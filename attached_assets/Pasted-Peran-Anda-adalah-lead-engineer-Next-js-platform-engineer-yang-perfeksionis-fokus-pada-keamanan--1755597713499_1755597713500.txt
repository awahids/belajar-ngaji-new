Peran: Anda adalah lead engineer Next.js + platform engineer yang perfeksionis, fokus pada keamanan, UX admin yang cepat, dan data yang rapi.

Tujuan

Bangun CMS Admin lengkap dengan 1 role: super_admin.
Kebutuhan:

CRUD semua konten (Hijaiyah, Zikir, Artikel, Kuis, Modul, Nilai, Fitur, Media).

Kelola Form Masuk (Hubungi Kami): status alur NEW → IN_PROGRESS → RESOLVED/ARCHIVED/SPAM, label, assign, export CSV.

Front site publik tetap tanpa login; CMS hanya untuk super_admin.

Stack & Standar

Next.js 15+ (App Router, RSC), TypeScript, TailwindCSS, shadcn/ui, framer-motion (animasi ringan).

Prisma + Supabase Postgres (DATABASE_URL).

Supabase Auth (email+password atau magic link) + allowlist email + claim JWT role=super_admin.

Supabase Storage untuk upload media (gambar/audio).

Server Components untuk read; Server Actions untuk write (create/update/delete).

ISR + revalidatePath/revalidateTag supaya front site ikut terbarui.

ESLint + Prettier, error boundary, toast notifikasi.

Keamanan & Akses

Seluruh route /admin/** dilindungi middleware:

Hanya user login Supabase dan (email ∈ ADMIN_EMAILS atau JWT role='super_admin') yang boleh masuk.

Jika gagal → redirect ke /admin/login.

RLS Supabase: semua tabel konten di-protect; policy hanya izinkan super_admin untuk SELECT/INSERT/UPDATE/DELETE.

Header keamanan global (HSTS, nosniff, referrer-policy, CSP ketat).

Pola Data & Mutasi

Read: via RSC (Prisma) untuk list & detail.

Write: via Server Actions (create/update/delete, reorder).

Isi createdBy/updatedBy/handledBy dari email user super_admin.

Setelah mutasi, panggil revalidatePath('/','layout/route terkait') atau tag supaya halaman publik ikut update.

Slug otomatis untuk Artikel & Kategori Kuis (unique).

Import CSV/JSON (quiz): tampilkan mapping kolom → simpan batch transactional.

Validasi & Form Fields (contoh inti)

Hijaiyah: order (int ≥1), letter (wajib), nameId (min 2), audioUrl (opsional, file ≤ 5MB, tipe audio).

Zikir: timeOfDay (pagi|petang), order, arabic (wajib, RTL), latin (opsional), meaningId (opsional, ≤ 600 char), repeat (≥1), source (opsional URL), audioUrl (opsional).

Artikel: title (min 4), slug (auto), coverUrl (opsional image), excerpt (≤160), bodyMd (markdown), status (DRAFT|PUBLISHED), publishedAt (auto saat publish).

Quiz:

Kategori: title (min 3), slug (auto).

Pertanyaan: question (min 6), 4 opsi (min 1 benar), explanation (opsional), reference (opsional).

Modul/Nilai/Fitur: order, title, excerpt/body, iconUrl/imageUrl (opsional), isActive.

Media: upload validasi tipe/ukuran; simpan ke MediaAsset.

ContactMessage: status & labels bebas; export CSV berdasar filter aktif.

Reusable Hal di Semua List Page

Kolom default: Name/Title, Status/Active, UpdatedAt, Actions (Edit/Delete).

Toolbar: search (debounced), filter (select), date range (contacts), tombol New, Export (contacts), Reorder (yang punya order).

Pagination: 20/baris (ubah via select).

Bulk actions: Hapus, Ubah status, Arsip/Spam (contacts).

Acceptance Criteria (harus terpenuhi)

Semua halaman /admin/** di atas terbuat & terhubung, dengan proteksi auth (hanya super_admin).

CRUD lengkap dan berfungsi di setiap entitas (termasuk upload media & drag reorder).

Form Masuk mendukung: filter, label, assign, ubah status, export CSV, mailto.

Mutasi konten memicu revalidate sehingga front site publik ter-update.

Validasi form (zod) + toast + error state rapi.

RLS aktif: hanya super_admin yang bisa akses tabel; data publik tidak diekspos ke klien.

UX admin cepat (search/sort/pagination), tanpa error ESLint/TypeScript.

Header keamanan aktif (HSTS, nosniff, referrer-policy, CSP).

Bonus (opsional)

Activity Log (AuditLog) untuk jejak perubahan penting.

Import soal kuis dari CSV/JSON dengan mapping kolom yang fleksibel.

Theme admin (light/dark).

Keyboard shortcuts (N=New, S=Save, Del=Delete, / = Focus search).

Output akhir: CMS lengkap siap produksi, aman, cepat, dan nyaman dipakai. Hanya super_admin yang bisa mengakses admin; seluruh konten front site tetap publik tanpa login.
